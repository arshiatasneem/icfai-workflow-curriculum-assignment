# ICFAI Workflow and Curriculum Assignment

This repository contains my work for both assignment tasks. **Task 1** focuses on studying and improving the hostel-leave process at ICFAI, while **Task 2** examines the B.Tech Data Science and Artificial Intelligence curriculum for the 2023 admission batch.

## Repository Contents

- **[Task 1: College Workflow](Task-1-College-Workflow/README.md)** — Analysis of the existing hostel-leave process, proposed workflow improvements, synthetic test cases, and estimated time savings.
- **[Task 2: Curriculum Audit](Task-2-Curriculum-Audit/README.md)** — Curriculum mapping, proposed changes, job-description comparisons, and AI-assisted exercises.
- **[AI-Use Record](evidence/ai-use-record.md)** — Documentation of the AI tools used during the assignment.

## Approach

### Task 1: College Workflow

I examined the hostel-leave process at ICFAI and referred to the official hostel rules to understand the existing requirements. Based on this understanding, I proposed a revised workflow with defined statuses, approval boundaries, exception handling, and recovery steps.

The proposed workflow is evaluated using five synthetic cases covering normal requests, missing information, duplicate submissions, unauthorized actions, and failed steps.

Since I did not collect measured request volumes or processing-time data, the time-saving calculations are presented as estimates using illustrative scenarios rather than verified results.

### Task 2: Curriculum Audit

I examined the B.Tech Data Science and Artificial Intelligence curriculum for the 2023 admission batch using the curriculum sources documented in the repository.

The audit maps the curriculum, identifies potential areas to keep or improve, and proposes changes based on course relevance, practical learning needs, and industry job-description requirements. It also includes AI-assisted exercises for selected subjects and records the supporting evidence, assumptions, and limitations.

The proposed changes are recommendations for consideration, not official curriculum changes.

## Evidence and Limitations

The repository includes supporting documents, source references, assumptions, calculations, and test cases for both tasks.

Throughout the assignment, I distinguish documented information from estimates, assumptions, and proposed improvements. Where direct measurements or independent validation were unavailable, I state those limitations rather than presenting unverified information as established fact.

## Purpose

The objective of this assignment is to apply structured analysis and evidence-based reasoning to two practical areas:

1. Improving an administrative workflow while preserving the required approval and authorization controls.
2. Evaluating a technical curriculum and proposing realistic, evidence-informed improvements aligned with learning outcomes and industry expectations.
