# Task 1 — College Workflow Investigation

**Chosen process:** Hostel leave request and approval.

This investigation examines the existing hostel-leave process and proposes a coordination tracker to improve request visibility and reduce unnecessary follow-ups. The current-process description is based on a hostel resident's account and the official IFHE Hostel Rules and Regulations (2018), rather than direct observation or a staff interview.
