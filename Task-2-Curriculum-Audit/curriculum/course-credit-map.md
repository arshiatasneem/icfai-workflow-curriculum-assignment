## Elective alternatives — published webpage

The published webpage lists professional-elective options under AI specialisation, Big Data Systems, Data Engineering, NLP and Data Science specialisations. Examples include DS403 Responsible AI, DS406 NoSQL Databases, DS408 Scalable Machine Learning Algorithms, DS415 Data Integration Tools, DS416 Text Mining, DS419 Automatic Speech Recognition and DS425 Introduction to Analytics Tools. These are **alternatives**, not a set of courses every student completes. Do not sum all listed options.
